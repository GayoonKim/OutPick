# ADR-025: 검증은 프로그램적 게이트로 실행·판정한다

상태: revised — 2026-09-30 사용자 요청으로 간소화. 이전의 별도 App·계정·자동 전달·병합 통제 인프라 설계를 대체한다. 기존 파일명은 문서 링크 호환을 위해 유지한다.

## 결정

2026-10-01 사용자 요청으로 모델을 갱신했다. 기존 역할·게이트 절차·사용자 수동 전환 원칙은 유지한다.

- 사용자가 GPT-6.1 Sol High와 GPT-6.1 Sol Light를 직접 선택한다.
- GPT-6.1 Sol High는 사용자와 설계·계획·테스트·합격 기준을 검토하고 결과를 분석한다.
- GPT-6.1 Sol Light는 승인된 구현과 게이트 실행 후 실제 결과를 보고한다.
- 게이트가 필수 검사·실제 실행·누락·실패를 프로그램으로 판정한다.
- AGENTS.md는 운영 지침이며 그 자체가 실행기나 권한 통제 장치는 아니다.
- 테스트의 충분성은 사용자와 GPT-6.1 Sol High가 검토한다. 코드화되지 않은 요구사항까지 자동 증명한다고 주장하지 않는다.

## 이유와 범위

모델 역할 분담과 필수 검증을 반복하기 위해 필요한 최소 구성부터 도입한다. 관리자/에이전트의 의도적인 우회 방지, GitHub App 기반 발행, 전용 계정·격리 인프라, 3개 OS용 독립 공개 제품은 이번 도입에서 제외한다. 기존 보안 설정을 해제하지 않는다.

## 상태와 연결

저장소 외부의 공용 Node 실행기와 OutPick의 다섯 검사 설정 연결을 완료했다. 실행 결과는 로컬 summary.json에 보존한다. GitHub CI나 필수 status check 연결은 포함하지 않으며, 파일명에 남은 ‘병합 통제’는 현재 구현 보장을 뜻하지 않는다.
