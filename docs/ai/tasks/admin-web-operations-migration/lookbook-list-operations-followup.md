# 관리자 웹 룩북 목록·운영 지침 후속 작업

2026-10-07 사용자 확정. Q7과 분리해 기록하며, 현재 구현을 시작하지 않는다.

## 확정된 방향

- 최근1~2년의 룩북을 중심으로 최근 발매한 룩북부터 확인·등록한다. 운영 지침이며 과거 룩북을 강제로 제외하지 않는다.
- 일반 시즌·콜라보를 같은 기준으로 다루며 콜라보 우선순위는 없다.
- 목록은 원본 사이트 순서를 유지한다. 발매일 추출·미확인 표시·날짜 검수·날짜 기반 재정렬은 범위에 포함하지 않는다.
- 기존 탐색 결과 snapshot에서 처음10개, 더보기10개씩 조회·표시한다. 원격 탐색을10개마다 중단·재접수하지 않는다.
- 페이지를 넘겨도 선택을 유지하며 표시 단위를 선택 수 제한으로 사용하지 않는다. 기존 서버 기술 상한80의 변경·초과 입력 자동 분할은 승인되지 않았다.
- 운영 화면은 관리자 웹이다. Q7을 위해 iOS 관리자 화면에 새 목록 기능을 추가하지 않는다.

## 후속 작업 진입 조건·설계 범위

Q7 복구 검증과 결과 정리 후 관리자 웹 작업에서 진행한다. 웹의 기술 선택·화면/API 계약을 먼저 설계하고 사용자 구현 승인 뒤 구현한다. 동일 snapshot/generation의 cursor, 목록 갱신·만료, 선택 보존, 인가, 중복·누락 없는 추가 조회를 세부 설계와 필수 검사에 포함한다. 기존 전체 탐색과10개 표시를 구분해 원격 요청량 절감 효과를 과장하지 않는다.

이 문서는 확정 방향과 이관 기록이다. 웹 phase·코드 구현·배포·데이터 변경·추가 유료 검증을 승인한 것으로 해석하지 않는다. 목록 기능 미구현은 별도로 남기며 Q7 통과로 대신 표시하지 않는다.
