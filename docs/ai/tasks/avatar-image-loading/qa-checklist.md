## 계측·판정

동일 화면/자료·첫 방문과 warm cache·스크롤 방향/기간을 기록한다. 요청수/성공 body 바이트/디스크 쓰기·크기·활성 작업·가능한 CPU/메모리/프레임을 비교한다. 서버/API 개인정보 원문을 로그에 넣지 않는다. 실제 저장 정책은 화면 체감만으로 판정하지 않는다.

실제 xcodebuild 실행 전 destination ID를 조회해 선택한다. scheme은 저장소의 OutPick-Development.xcscheme을 사용한다. build-for-testing → 필요한 suite의 test-without-building 순으로 실행하고 명령·환경·결과 경로는 progress/phase-5.md에 남긴다. 테스트 구현 전에는 실행 가능한 가짜 suite 이름으로 완료 명령을 제시하지 않는다.
