# 결정 인덱스

> Phase2 구현 선택(2026-09-18): 사용자가 지정·확인한 DEV 본인 썸네일로 PNG/JPEG를 비교하고 승격 encoder를 JPEG0.8로 적용했다. PNG211,022bytes 대비 JPEG33,006bytes, UIKit Simulator 중앙7.17ms 대비1.31ms. 단일 표본이며 실기기 스크롤 QA에서 재검토한다. [비교 근거](progress/phase-2.md). 확대 원본은 재인코딩/영속 캐시 대상이 아니다.
