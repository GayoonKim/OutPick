# Phase 5 — 통합 검증과 완료

상태: 2026-09-21 합의 범위 완료. VoiceOver는 사용자 요청으로 제외. 자동·수동·코드대조를 조합한 실제 검증 범위와 계측 한계는 [최종 기록](../progress/phase-5.md), 항목별 근거는 [체크리스트](../qa-checklist.md) 참조. 새 서버배포/커밋 없음.

## 목표·변경 범위

Phase1~4를 통합해 자동 테스트 실행, Development 실기기 QA, 성능/캐시 정책 확인 후 값과 한계를 문서화한다. 발견 결함 파일만 보완하며 기능 범위를 확대하지 않는다.

## 실행 순서

1. 현재 사용 가능한 Simulator와 연결 기기를 확인하고 OutPick-Development scheme으로 build-for-testing.
2. 새 정책/승격/session/presentation/viewport/retry suite와 기존 ImageLoadCoordinator·ImageCacheRevision·ImagePipelineResources·룩북 HTTP·프로필 변경·viewer 관련 회귀 실행.
3. iPhone14 OutPick-DEV를 기존 QA 기준 후보로 사용하되 현재 연결/설치/계정/자료 상태를 확인한다. 실제 적용 기기가 다르면 기록한다.
4. QA 체크리스트의 각 화면·변경·로그아웃·실패 복구를 확인한다. 운영 데이터나 앱 삭제를 자동으로 수행하지 않는다.
5. 첫 표시/재진입/빠른 왕복을 분리해 요청·바이트·활성 작업·캐시 writes·CPU/메모리/프레임을 가능 범위에서 계측한다. 원본 종료는 보유 참조·임시 파일로 검증하며 RSS 즉시 감소를 단독 기준으로 쓰지 않는다.
6. 선로딩/디스크 초기값 채택 또는 조정 이유, 표본/네트워크/캐시 한계를 기록한다. 실행하지 못한 항목은 완료로 표시하지 않는다.

## 완료 기준

[QA](../qa-checklist.md)의 필수 정책/경합/대표 화면 항목 통과, 필수 보류 없음 또는 사용자 명시 범위 조정, 관련 하네스 최신화. 신규 서버 배포 없음. 자동 테스트 개수는 실제 결과로 집계하며 이전91개를 이번 통과 결과로 재사용하지 않는다.

## 논의 필요·후속

측정 fixture/초기화 범위, 새 값 채택, 재현되지 않는 필수 시나리오의 제외는 증거와 함께 논의한다. 승인된 자동 테스트 실행을 다시 질문하지 않는다. 결과 요약 후 다음 핵심 항목은 채팅방 대표 이미지 설계다.
