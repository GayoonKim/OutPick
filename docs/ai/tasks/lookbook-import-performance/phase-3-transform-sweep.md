# C 구조 변환 동시성 12회 대조

2026-10-03. 사용자의 ‘다음 진행해도 문제 없으면 진행’으로 직전 추천한 추가 12회 대조를 승인받았다. [54회 탐색 결과](phase-3-comparison.md)의 후속이며 최적값 채택·제품 기본값 변경은 별도다.

**완료:** Mac/Linux 210개/필수 102개 게이트 통과, 12회 모두 성공·집계 valid true. 1/2는 시간 차이 약 0.56%, 4/전체 시작은 2보다 약 87~89% 느렸다. 이번 1 CPU·6시즌 조건에서 메모리 여유가 더 컸던 변환 1을 우선 후속 후보로 추천한다. 전체 부하/클라우드 최적값 확정은 아니다.

## 실행 계약

- C 구조, UNAFFECTED 6시즌, 변환 슬롯 1/2/4/전체 시작(null)을 각 3회로 총 12회 비교한다. 반복마다 순서를 한 칸씩 회전한다: 1→2→4→전체 / 2→4→전체→1 / 4→전체→1→2.
- 시즌 병렬 실행 폭 6, 다운로드 4, 업로드 4, 경로 저장 제한 없음, 재사용 off, 해시/저장 유한 입력 제출 정책은 고정한다. 한 이미지의 출력은 기존 썸네일/상세 2개다.
- 전체 시작은 앱의 변환 슬롯 제한 제거이며 libuv/libvips 내부 pool을 제거하지 않는다. 같은 Worker 실행의 모든 시즌이 변환 슬롯을 공유한다.
- 매회 새 고정 이미지 컨테이너, Linux ARM64 Node 24, 1 vCPU·2GiB·swap 없음·네트워크 없음, 같은 읽기 전용 Linux 입력 volume, 전체 입력 무결성 검사 이후부터 측정한다. cold-cache라고 표기하지 않는다.
- 메모리 표본 100ms, 간격 500ms 초과 환경 중단, 메모리 85% 이상 1초 지속 시 해당 회차 중단을 유지한다. 메모리 중단은 분모에 남기고 다음 회차를 진행하며 정합성/환경 오류는 후속 실행을 보류한다.
- 이번 변환 2의 새 3회가 기준선이다. 이전 이미지/소스의 54회 표본과 합치지 않는다. 세 번 모두 성공한 설정에만 시간 중앙값을 계산하고 첫 시즌/CPU/메모리/대기열도 함께 기록한다.

## 구현·검증 범위

변경 파일은 Worker `src/performance/comparison.ts`, `comparison-report.ts`, 새 `transform-sweep.test.ts`, `verification/lookbook-import.json`과 관련 진입점이다. 컨테이너 실행/메모리 감독/고정 자료/제품 추출·JPEG 함수는 기존 연결을 재사용한다. 앱 DI/Container/Coordinator, API/Firestore 계약, 운영 설정 변화는 없다.

`makeTransformSweepPlan`이 별도 ID/settings digest를 만들고 `validateComparisonPlan`이 12회 승인 조합과 정확히 일치하는지 확인한다. `runComparison`은 검증 후 변환 슬롯만 바꾼다. `summarizeComparisons`는 원래 54회와 새 12회를 구분해 완전한 계획·중복/누락·고정 이미지·결과 identity를 검증하며 변환 수치별로 집계한다. 전체 시작 null과 필드 누락을 구분한다.

추가 필수 테스트 3개: 승인 조합/다른 축·잘못된 설정 거절, 시즌 공용 실제 슬롯 peak/기존 정책 유지, 설정별 3회 집계/중단 분모/누락·혼입 거절. fake 메모리와 비동기 작업으로 슬롯을 검사하며, 실제 JPEG 정합성과 Linux 안전 감독은 12회 실험에서 다시 확인한다. 필수 구성은 전체 210개/required ID 102개다. 사용자 화면 QA나 실제 Storage/Firestore 검증은 이번 로컬 변경 범위에 포함되지 않는다.

## 추천과 다음 검토 범위

이번 조건에서는 **C 구조의 변환 1을 우선 후보, 2를 대조 후보**로 남긴다. 1/2 시간 차이는 작지만 1의 관측 메모리 여유가 더 컸다. 4나 변환 제한 해제를 추천할 실측 근거는 없었다. 1 CPU에서 얻은 결과이며 더 많은 CPU나 다른 이미지/실제 업로드의 최적값을 보장하지 않는다. 다운로드·업로드 4도 이번 로컬 자료/spy로 최적성이 검증된 숫자는 아니다.
